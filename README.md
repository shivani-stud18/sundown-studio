# Sundown Studio Website

A modern, responsive studio-style website built with HTML, CSS, and JavaScript, focused on smooth scrolling, interactive sections, animations, sliders, and a visually engaging user experience.

## 🚀 Live Demo

[View Live Website](https://sundown-studio-coral.vercel.app/)

## 📌 About the Project

This project is a front-end studio website created to practice modern web design, responsive layouts, smooth scrolling, and interactive user experiences.

The website focuses on creating an immersive and visually engaging interface using JavaScript interactions, smooth scrolling, responsive sections, image transitions, and slider components.

The project was developed with a tutorial/reference as part of my learning process, with a focus on understanding and implementing the frontend concepts used throughout the website.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Smooth scrolling experience
- Interactive navigation
- Animated sections and transitions
- Interactive image/content slider
- Swiper.js integration
- Responsive layouts
- Hover effects and micro-interactions
- Modern studio/agency-style UI
- Responsive footer section
- Mobile-friendly design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Locomotive Scroll
- Swiper.js
- Remix Icon
- Git & GitHub
- Vercel

## 🎨 UI & Interaction

The website focuses on creating a modern and interactive frontend experience through:

- Smooth scrolling
- Scroll-based effects
- Image transitions
- Hover interactions
- Slider animations
- Responsive navigation
- Interactive content sections
- Responsive media behavior

## 📱 Responsive Design

The website is designed to adapt to different screen sizes using responsive layouts and media queries.

Desktop, tablet, and mobile layouts are adjusted to provide a consistent and usable experience across different devices.
